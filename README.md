# Посмотри в окно

Учебный проект второго спринта курса «Фронтенд-разработчик» от Яндекс Практикума.

«Посмотри в окно» — веб-приложение для просмотра видеозаписей из разных городов. Пользователь может выбирать город, фильтровать видео по времени суток и переключаться между доступными роликами.

## Функциональность

- Поиск видеозаписей по названию города.
- Фильтрация по времени суток: утро, день и ночь.
- Переключение между видеокарточками.
- Загрузка дополнительных результатов.
- Отображение состояния загрузки.
- Обработка ошибок получения данных и отсутствия подходящих видео.
- Интерактивные состояния кнопок, полей ввода и карточек.

## Технологии

- HTML5 — структура и семантическая разметка.
- CSS3 — оформление интерфейса, Flexbox и псевдоклассы.
- JavaScript — работа с API и управление видеоконтентом.
- БЭМ — организация CSS-классов.
- Git и GitHub — контроль версий.

## Запуск проекта

1. Клонировать репозиторий: `git clone https://github.com/LOI1K/posmotri-v-okno-ad.git`
2. Открыть папку проекта в VS Code.
3. Запустить `index.html` с помощью расширения Live Server.

Для загрузки видео необходимо подключение к интернету.

## API

В проекте используется API видеоконтента по адресу:

https://v-content.ffapi.ru

Доступность видеозаписей зависит от работы внешнего сервиса.
